# AdminOnlyLoginIP v1.0

> **Язык:** Русский · [English](readme.en.md)

Minecraft плагин привязки входа к IP-адресу. Привязывает UUID игрока к конкретному IP — при входе с другого IP игрок кикается. Работает с `online-mode: false`.

---

## Требования

- Paper 1.20+ (или совместимый Spigot/Paper/Purpur)
- Java 17+

---

## Установка

1. Скопируйте `AdminOnlyLoginIP-1.0.jar` в папку `plugins/`
2. Перезапустите сервер
3. Настройте `plugins/AdminOnlyLoginIP/config.yml` при необходимости

---

## Как это работает

1. Игрок выполняет `/aoli add <ник>` — плагин сохраняет его UUID, ник и текущий IP в `data.yml`
2. При каждом входе плагин проверяет: если UUID игрока есть в базе, его IP должен совпадать с сохранённым
3. Если IP не совпадает — игрок кикается
4. Проверку можно отключить командой `/aoli off` (полезно при смене IP)

---

## Быстрый старт

### 1. Добавьте игрока

Встаньте в игре и выполните:

```
/aoli add <ник>
```

Это сохранит ваш UUID, указанный ник и ваш текущий IP-адрес.

### 2. Попробуйте зайти с другого IP

Если IP не совпадает с сохранённым — вас кикнет с сообщением из конфига.

## Настройка

### config.yml

```yaml
# Включить проверку IP (true/false)
enabled: true

# Сообщение при кике за несовпадение IP
kick-message: Доступ запрещён
```

| Параметр | Описание |
|----------|----------|
| `enabled` | Глобальный переключатель проверки IP. `false` — все могут зайти с любого IP |
| `kick-message` | Сообщение, которое увидит игрок при кике |

---

## Команды

| Подкоманда | Аргументы | Описание |
|------------|-----------|----------|
| `/aoli add <ник>` | `<ник>` | Сохранить UUID + IP текущего игрока |
| `/aoli delete <ник>` | `<ник>` | Удалить запись по нику |
| `/aoli on` | | Включить проверку IP |
| `/aoli off` | | Выключить проверку IP |
| `/aoli reload` | | Перезагрузить config.yml |
| `/aoli list` | | Показать все записи |
